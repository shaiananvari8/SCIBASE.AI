# Requirements Map

| Issue #13 requirement | Coverage |
| --- | --- |
| AI Citation Tool | Evaluates citation recommendations before one-click insertion based on venue-level integrity risk. |
| Context-aware retrieval from open-access corpora | Adds a safety gate for retrieved candidates so questionable venues do not silently become suggestions. |
| Ensure completeness and relevance of references | Blocks or warns on venue risks that make a reference unsafe despite matching topic text. |
| AI Peer Review Aid | Emits reviewer-ready actions for citation hygiene and publication-quality checks. |

## Non-Overlap

This is not a citation metadata duplicate resolver, citation context-fit assistant, style formatter, citation diversity auditor, retraction watch, manuscript similarity triage, ethics/data availability auditor, statistical checker, reporting-guideline checker, or broad AI tools suite. It focuses narrowly on venue-level trust and unsafe one-click citation insertion prevention.
